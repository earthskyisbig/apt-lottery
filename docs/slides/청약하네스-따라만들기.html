HTTP 401 계속
활용신청이 아직 승인 전이거나 다른 서비스에 신청한 경우입니다. 마이페이지에서 승인을 확인하세요.
리포트가 비었다
최근 90일 수도권 신규 공고가 실제로 없을 수 있습니다. --lookback-days 180으로 넓혀보세요.
경쟁률 표가 비었다
정상입니다. 경쟁률·가점은 별도 서비스라 미연동이고, 리포트에도 그렇게 안내됩니다.

가져갈 네 가지

→ 공식 API를 직접 호출. 래퍼는 서버측 필터를 못 쓰는 경우가 많습니다.

→ 원본 그대로 저장하고 해석은 다음 단계로. 유형이 늘어도 안 깨집니다.
✓ 모르는 건 폴백 체인으로 짠다
키 형태를 추측하는 대신 네 방식을 시도하게 하면, 아무 키나 넣어도 동작합니다.
✓ 실패를 화면까지 끌고 온다
인증 실패·누락은 notes로 전달해 리포트에 노출. 성공한 척하는 빈 리포트가 제일 위험합니다.
