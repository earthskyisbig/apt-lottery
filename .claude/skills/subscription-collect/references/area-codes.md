# 청약홈 지역 통계 코드 (SUBSCRPT_AREA_CODE)

`get_apt_subscription_results`의 `area_code`에 쓰는 청약 지역코드다.
**주의**: 실거래가 API용 5자리 법정동 코드와 다르다.

## 수도권 (관심 대상)
| 지역 | area_code |
|------|-----------|
| 서울 | 100 |
| 인천 | 400 |
| 경기 | 410 |

## 참고: 기타 광역 (필요 시)
| 지역 | area_code |
|------|-----------|
| 부산 | 200 |
| 대전 | 300 |
| 대구 | 700 |
| 광주 | 500 |
| 울산 | 680 |
| 세종 | 339 |

## 검증 원칙
위 코드는 알려진 값이나 API 버전에 따라 다를 수 있다. 조회 결과가 **모든 수도권 지역에서 일관되게 비어있으면** 코드 불일치를 의심하라:
1. `area_code` 없이 `stat_kind`+`stat_year_month`만으로 호출해 전체 응답의 지역 필드를 확인
2. 응답에 실제 쓰이는 지역코드 값을 파악해 매핑을 보정
3. 보정한 매핑을 이 파일에 반영(하네스 진화)

빈 결과가 특정 연월/지역에서만 나오는 것은 정상(해당 기간 청약 없음)이다. 코드 오류와 혼동하지 말 것.
