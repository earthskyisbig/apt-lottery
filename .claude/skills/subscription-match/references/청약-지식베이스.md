# 청약 지식베이스 (개인 조건 매칭용)

> 출처: 청약 강의 29~33강(카레라, 2024 기준) + **2025~2026 개정 반영**(§8 참조).
> 제도·규제(투기과열지구, 분양가상한제, 전매제한, 실거주의무, 특공 소득기준, 월납입 인정액,
> 비아파트 무주택 기준 등)는 정권·법 개정마다 바뀐다. **§8은 2026년 현재 정착된 최신 개정이며,
> 그마저도 이후 재개정될 수 있으므로 자격·순위·규제의 최종 판단은 반드시 최신 청약홈/뉴홈 공고
> 원문으로 크로스체크**한다. 이 문서는 "내 조건에 맞는 공고 1차 선별"용이며 확정 판정이 아니다.

## 목차
1. 주택 분류 (국민/민영, 분양/임대)
2. 공급 방식 (특별공급 / 일반공급 / 무순위)
3. 특별공급 자격 (세대유형별)
4. 일반공급 — 국민주택(순위·저축총액) vs 민영주택(가점제/추첨제)
5. 청약 가점 계산 (84점 만점) + 무주택 인정 기준
6. 당첨확률 높이기 전략 (빈집털이) + 부부 청약 규칙
7. 수익성 — 안전마진과 규제
8. **2025~2026 개정 요약 (2026 현재 기준)** ← 최신

---

## 1. 주택 분류
- **국민주택**: 국가·지자체·LH/SH가 공급, 전용 **85㎡ 이하**. 공공분양. (뉴홈 정책 대상)
- **민영주택**: 그 외 브랜드 아파트(래미안·힐스테이트·자이 등). 민간분양.
- 청약통장은 **분양**에만 소멸(임대는 순위 참고용으로만 사용, 소멸 안 됨).

## 2. 공급 방식 (우선순위 = 처리 순서)
특별공급 → (우선공급) → 일반공급 1순위 → 2순위 → **무순위·잔여세대(줍줍)**
- **특별공급**: 정책 배려 계층, 청약경쟁 없이. **1세대당 평생 1회**. 일반공급과 **동시 신청 가능**(같은 단지 한정, 특공 1건 + 일반 1건).
- 물량 비중(대략): 국민주택 특공:일반 ≈ 8:2, 민영주택 ≈ 5:5. 공공분양 일반공급 비중은 보통 15~20%(많으면 30%)로 **갈수록 축소**.
- **무순위/잔여**: 자격·가점 무관 "아무나" 가능(무순위 사후접수·임의공급·계약취소주택). 최초 분양가(3~4년 전)로 공급되는 경우가 많아 시세차익 기회.

## 3. 특별공급 자격 (세대유형 → 해당 특공)
> 정부 최우선 시책 = 저출산 대응. 신혼·신생아·다자녀·청년·생애최초에 우선 배정.

| 세대유형 | 해당 특공 | 핵심 조건 / 메모 |
|---------|----------|-----------------|
| **신혼부부(혼인 7년 이내)** | 신혼부부 특공(공공+민영) | 혼인신고 완료 시 공공·민영 모두. |
| **예비 신혼부부** | 신혼부부 특공(**공공만**) | 입주 전 혼인신고 후 증명. 민영 신혼특공 불가. |
| **신생아(공고일 기준 2년 이내 출생)** | 신생아 우선공급 | 줄세우기에서 **신생아 최우선**, 그 안에서 소득기준. 공공은 신생아 특례가 우선공급에 포함. |
| **미성년 자녀(신생아 아님)** | 신혼 특공 내 1순위 | 신생아 없지만 미성년 자녀 → 1순위 경쟁. |
| **다자녀(미성년 자녀 2명 이상)** | 다자녀 특공 | **2023.3 개정으로 3명→2명 완화**(청약홈 특별공급 안내 원문, 2026-09 확인). 국민(공공특법 미적용) 소득 120%↓. |
| **노부모부양(만65세↑ 직계존속 3년 이상)** | 노부모부양 특공 | **세대주만 신청 가능**(원문). 무주택세대원은 불가. |
| **1인가구/미혼 단독** | (생애최초 제한적) | 미혼 1인가구는 **생애최초 특공: 전용 60㎡ 이하 + 전원 추첨**. 사실상 운. 특공 기대 낮음 → 일반공급/무순위 위주. |
| **생애최초(과거 주택소유 이력 없음)** | 생애최초 특공 | 세대 전원 무주택 이력 + **5년 이상 소득세 납부자**(원문). 소득 130~160%↓. 1인가구는 60㎡ 이하 제약. |
| **청년(만19~39세 미혼 무주택)** | 청년 특공(**공공주택만**, 15%) | 소득 140%↓, 자산 소득3분위 순자산 80%↓. 민영엔 없음. |
| **기관추천** | 기관추천 특공(10%, 85㎡↓) | 국가유공자·장애인·북한이탈주민 등. 공고별 확인. |

- **특공 공통 요건(원문)**: 무주택세대구성원 + **청약통장 6개월 이상** 가입. 신혼 소득 140~160%↓·부동산 자산 3억 3,100만원↓, 신생아 130~160%↓.
- **특공 배정 비율(원문, 2026-09)**: 기관추천 10% · 신혼 민영15/국민20% · 다자녀 10~15% · 노부모 국민5/민영3% · 생애최초 민영7/국민20% · 신생아 민영10/국민15% · 청년 공공15%. 실제 주택형별 배정세대는 API 주택형별 데이터가 정확하니 그 값을 우선.

- **줄세우기 원리(신혼·신생아)**: ①신생아 우선 → ②소득기준 이하 → ③미성년 자녀 1순위 → ④일반. 각 단계 낙첨 시 다음 단계 자동 재도전.
- **소득**: 기준소득 이하가 우선. 고소득이면 신혼특공은 얌전히 추첨으로.

## 4. 일반공급
### 1순위 요건 (청약홈 청약자격 안내 원문, 2026-09 확인) — 규제지역이면 두 배
| 구분 | 규제지역(투기과열·청약과열) | 수도권 비규제 | 수도권 외 |
|------|---------------------------|--------------|----------|
| 국민주택 | 가입 **2년 + 납입 24회** | 가입 1년 + 12회 | 6개월 + 6회 |
| 민영주택 | 가입 **2년** + 지역·면적별 예치금 | 가입 1년 + 예치금 | 6개월 + 예치금 |
- **규제지역 1순위 강등(→2순위)**: 세대주가 아닌 자 · 과거 5년 내 다른 주택 당첨 세대원 · (민영) 2주택 이상 세대원. 추가로 **수도권 공공주택지구 민영주택·85㎡ 초과 공공건설임대**는 규제 여부와 무관하게 2주택 이상 세대가 2순위(원문, API `PUBLIC_HOUSE_EARTH_AT` 로 판별).
- **유주택자의 민영 청약(원문)**: 민영주택은 무주택 요건이 없다 — 1주택·다주택 세대도 청약통장 1순위면 1순위 접수 가능(추첨제, 무주택 우선 배정 뒤 잔여). **국민주택만 무주택세대구성원 한정**. 매칭 엔진은 유주택자를 국민에서만 제외하고 민영은 순위 판정을 거쳐 남긴다.
- 수도권 비규제 1년 요건은 시·도지사가 **24개월까지 연장 가능**(수도권 외 6→12개월) → 공고 원문의 가입기간 요건을 우선. 순위 발생 기준일 = **최초 입주자모집공고일**. 청약저축 가입자는 공고일 전일까지 청약예금 전환 시 민영 청약 가능.
- 청약부금 통장은 **85㎡ 이하만** 청약 가능. 예·부금은 종합저축 전환(§8-3) 권고.
- 규제지역 여부는 공고의 `regulation.speculation_zone`(API) 또는 주소 목록(analyze 스킬 `regulated-zones.md`, 2026-09-05: 서울 전역 + 경기 과천·광명·수원 영통/장안/팔달·성남 분당/수정/중원·안양 동안·용인 수지/기흥·화성 동탄·의왕·하남·구리).

### 국민주택 (가점제 없음, 순위+저축총액)
- **1순위 조건(수도권 비규제)**: 통장 가입 **1년** 경과 + 월납입 **12회** 이상. 규제지역은 2년+24회.
- 1순위 내 줄세우기(40㎡ 이상): ① **무주택 3년 이상 세대구성원** + **저축 총액 많은 순** → 남은 물량은 저축총액 순.
- 수도권 당첨선: **저축 총액 대략 2,000만원 중반 이상**(사례: 대방A1 2,580만·수방사 2,550만). 비수도권은 수백만원대도 가끔.
- **월납입 인정액 25만원 (2024.11 시행 → 2026 현재 정착)**: 과거 10만원 시절엔 2,000만원 채우는 데 18~20년. 이제 **25만원씩이면 8~9년이면 공공분양 안정권(2,000만원 중반)** 도달. → **20대·사회초년생은 지금 당장 매월 25만원 납입이 강력한 정답**.
- **판단**: 25만원씩 장기 납입할 각오면 국민주택 목표(20대 후반~30대 초 1순위 당첨 기대 가능). 아니면 **국민주택 포기, 민영 추첨제로**.

### 민영주택 (1순위 → 가점제 / 추첨제)
- 1순위: 가입기간 + **예치기준금액** 충족(납입횟수 무관). 예치금은 지역·평형별 기준. 최소 **1,500만원 + 가입 2년**이면 통상 안전.
- **가점제**: 무주택기간+부양가족+통장기간(아래). 서울·수도권 당첨선 대략 50점대 후반~70점대. **60점 이상은 40대 중반 이상+부양가족多**라야 가능 → 20~30대·1인가구는 가점제 사실상 불리.
- **추첨제**: 무주택자 또는 1주택자(당첨 시 기존주택 처분 조건) 지원 가능. 규제지역·수도권·광역시 민영은 1순위 추첨물량의 **75%를 무주택 세대원 우선**.
- **가점제/추첨제 비율**: 투기과열지구·인기지역·큰 평수일수록 가점제↑, 비인기·소형일수록 추첨제↑. (청약과열지구·투기과열지구 지정은 시점마다 변동 → 최신 확인)

## 5. 청약 가점 (84점 만점) + 무주택 인정 기준
| 항목 | 만점 | 기준 |
|------|------|------|
| 무주택 기간 | 32점 | 15년 이상. (성인 이후·혼인·과거 소유이력에 따라 기산점 다름 → 계산 필요) |
| 부양가족 수 | 35점 | 7인 이상. 실질 4인(부부+자녀2)도 드묾. |
| 통장 가입기간 | 17점 | 15년 이상. |
- 실질 만점 취급 ≈ **69점**(32+20+17). 40~50대 장기 무주택 세대주라야 확보.
- **배우자 통장기간(가점 4번째 항목, 청약홈 용어설명 원문 "0~2년 이상")**: 민영 가점제에서 배우자 청약통장 가입기간을 **1년 미만 1점 · 1~2년 2점 · 2년 이상 3점**으로 합산(2024 개정·2026 정착). ~~3년 이상 3점~~은 오기였음(2026-09-05 원문 대조로 수정).
- **무주택기간 기산(원문)**: **만30세**부터(만30세 전 혼인 시 혼인신고일부터). 다자녀 특공만 만19세부터. 30세 미만 미혼은 무주택기간 0.
- **부양가족 인정(원문)**: 배우자 · 직계존속(신청자가 세대주 + **3년 이상** 같은 등본, 존속 부부 중 1명이라도 유주택이면 제외) · 직계비속(**미혼** 자녀 한정, 만30세 이상 자녀는 1년 이상 같은 등본). 형제자매·동거인은 세대원 아님.
- **60세 이상 직계존속의 주택**은 무주택 판정 시 없는 것으로 봄(단 **노부모부양 특공·공공임대는 예외**로 유주택 취급).
- **민영 예치금 기준표(원문, 만원 · 신청자 거주지 기준)**: 서울/부산 85㎡↓300 · 102↓600 · 135↓1,000 · 모든면적 1,500 / 기타 광역시(인천 등) 250·400·700·1,000 / 기타 시·군(경기 등) 200·300·400·500. **청약부금은 85㎡ 이하만**.

### 비아파트(빌라·오피스텔) 보유자의 무주택 인정 완화 (2025~2026 개정 — 중요)
소형·저가 비아파트를 가져도 **아파트 청약 시 무주택자로 인정**되어 가점·자격을 유지한다.
- **기존**: 전용 60㎡ 이하 + 공시가격 수도권 1.6억(지방 1억) 이하만 무주택 간주.
- **현재(원문 확인 2026-09-05)**: **단독·연립·다세대·도시형생활주택** 전용 85㎡ 이하 + 공시가격 수도권 5억(지방 3억) 이하 → 무주택 인정. **아파트는 여전히 60㎡·수도권 1.6억(지방 1억)** 기준. 조건: 세대가 그 주택/분양권을 **1호(1세대)만** 소유. 공공임대 청약엔 미적용.
- 실전: 수도권에 공시가 3억대 빌라 실거주 중이어도 무주택자로 청약 가능 → 가점 깎일 걱정 없이 유지. (단, 공고별 세부기준·해당 여부는 원문 확인)

## 6. 당첨확률 높이기 전략 ("빈집털이" — 눈치싸움) + 부부 청약 규칙
경쟁률이 낮게 찍히는 곳을 노린다. 실거래가는 결국 평수 따라가므로 "안 팔릴 걱정" 과도할 필요 없음.
- **애매한 평수**: 표준(59·84) 사이 비표준 평형(예: 73·74·77㎡). 경쟁률 절반 수준으로 뚝.
- **타워형(비선호)**: 판상형 선호 심리 → 타워형 경쟁률 낮음. 통풍 등은 서큘레이터로 해결 가능.
- **뒤쪽 알파벳**: 같은 84㎡라도 84A에 몰리고 84D·84E는 낮음(비합리적 심리).
- **적은 세대수 타입**: 소수 공급(예: 총 228 중 5가구)은 "설마 되겠어" 심리로 미달 경향.
- **모델하우스에 없는 평형**: 눈으로 본 타입에 몰리는 심리 → 없는 평형이 낮음.
- **동시분양(당첨자 발표일 동일) 단지 중 덜 선호 단지**: 같은 발표일이면 한 곳만 지원 가능 → 2~3등 단지에서 빈집털이. 단 "가장 애매한 3등"이 아니라 **중간 애매(2등)**가 실제로 더 빌 때가 많음(눈치싸움).
- **동시 신청 규칙**: 같은 단지 특공+일반은 먼저 당첨된 것 인정. **다른 단지 2곳에 넣고 발표일 같으면 전부 부적격**(예외: 부부가 각각 다른 단지 → 하나 인정).

### 부부 청약 규칙 (2024 개정 · 2026 정착)
- **부부 중복청약 허용**: 같은 단지에 부부가 각자 청약해 **둘 다 당첨돼도 무효 아님 → 먼저 접수한 1건을 유효 당첨**으로 인정(과거엔 둘 다 부적격). 즉 부부가 같은 단지를 함께 노려 당첨확률을 2배로 올릴 수 있다.
- **배우자 과거 이력 배제**: 배우자가 **혼인 전** 주택 소유·청약 당첨 이력이 있어도, **현재 세대가 무주택**이면 생애최초·신혼부부 특공 신청 가능.
- **배우자 통장기간 합산**: 민영 가점제에서 배우자 통장 가입기간 최대 3점 합산(§5 참조).

## 7. 수익성 — 안전마진과 규제
- **안전마진 = 주변 유사평형 시세 − 분양가**(무위험 차익). 로또 청약(원펜타스 20억, 동탄롯데캐슬 13억 등)은 분양가상한제 덕.
- **일반 청약**: 안전마진 1~2억 수준이 흔하고, 오차 ±5천만원도 큼 → **꼼꼼히 계산**. 부대비용 빼면 남는 게 없을 수도.
- **안전마진 계산 원칙**:
  - 주변 **더 나쁜 입지(한 칸 아래) 단지**와 비교(희망회로 금지).
  - 거래 없는 단지는 **인근에 거래 활발한 단지의 가격 동향**으로 유추. 네이버 호가 그대로 믿지 말 것.
  - **대장아파트** 기준 판단: 신축은 준신축 행동대장을 따라가되 구축 대장을 넘기 어려운 동네도 있음(연식보다 입지가 우선인 곳).
- **무순위/계약취소/임의공급**: 3~4년 전 분양가 → 시세차익 기회. 단 경쟁률만으로 흥행 판단 금지(계약률 낮으면 줍줍 물량↑).
- **규제(반드시 최신 확인)**: 전매제한(당첨일부터 N년 매매 제한), 실거주 의무(분양가상한제 당첨 시 입주 후 2~5년).
- **실거주의무 3년 유예 vs 임대차 2+2 갱신권 충돌 — 2026 현재 현실화(중요)**: 2024년엔 "충돌 우려"였으나, **둔촌주공(올림픽파크포레온) 등 입주 완료 후 실제 분쟁 속출**. 세입자의 갱신요구권 행사로 집주인이 실거주 의무를 못 지켜 **과태료 위기**에 처하는 사례 발생.
  - **안전 우회책(2026)**: ①세입자 들일 때 처음부터 **전세 계약기간을 명시적으로 3년으로 합의**, 또는 ②**2년 계약 후 실거주를 사유로 갱신 거절**하고 집주인이 입주하는 스케줄을 미리 계산. 특약에만 의존하지 말 것.
