# 개인 청약 매칭 스킬

`profile.yaml`(개인 조건)과 분석된 청약공고를 대조해 **"내 조건에 맞는 청약"을 압축 추천**한다.
판정이 아니라 **1차 선별**이다 — 최종 자격은 공고 원문으로 확인하라는 안내를 항상 붙인다.

## 반드시 먼저 읽을 것
- `references/청약-지식베이스.md` — 자격·가점·전략·안전마진 규칙 (강의 29~32강 근거, **2024 기준, 규제는 최신 확인**)
- `references/profile-schema.md` — 프로필 필드 정의 + 파생 계산

## 입력
- `profile.yaml` (프로젝트 루트). **없으면** 매칭을 건너뛰고 그 사실을 반환(리포트에 세팅 안내).
- `_workspace/02_analyst_summary.json` (수도권 필터·유형별 정리된 공고)

## 매칭 절차

### 1. 프로필 파생 계산
- **예상 가점** = 무주택기간점수 + 부양가족점수 + 통장기간점수 (지식베이스 §5). 값이 null이면 해당 항목 0 + `가점_불완전:true`.
- **국민 vs 민영 성향**: `account_monthly_manwon>=25` 또는 `account_total_manwon>=2000` → 국민주택 1순위 후보. 아니면 민영(예치금 충족 시 추첨).
- **추첨 우위**: 예상 가점 < 55 → 민영은 추첨제 중심.

### 2. 지역·면적 선호 필터
- `regions` 부분매칭(공고 위치 문자열). 비면 수도권 전체.
- `area_pref`는 주택형 데이터가 있을 때만 적용(현재 공고 상세엔 대표만 있으니 참고 태그).

### 3. 자격 매칭 (공고별)
각 공고에 대해 프로필의 `household_types`·`household_status`로 지원 가능 경로를 판정:
- **특별공급 후보**: 세대유형 → 지식베이스 §3 매핑. 예: `신혼부부`→신혼특공(공공+민영), `예비신혼`→공공만, `신생아`→우선공급, `다자녀`/`노부모`→해당 특공, `생애최초`→(1인가구는 60㎡↓ 전원추첨).
- **일반공급 경로**: 국민주택이면 순위+저축총액(국민 성향일 때 강추), 민영이면 가점제/추첨제(추첨 우위 여부 반영).
- **무순위/잔여·임의공급**: 자격 무관 → `household_status`가 1주택/다주택이어도 대부분 지원 가능(무순위는 무주택 요건 있는 경우 있으니 "원문 확인" 태그). **누구에게나 추천 후보**.
- 자격 불충족이 명확하면 제외하되, 애매하면 `자격_확인필요`로 남긴다(임의 탈락 금지).

### 4. 전략 태그 (profile.strategy_aggressive=true일 때 강조)
지식베이스 §6 신호를 공고/주택형에 태깅. 현재 수집 데이터로 가능한 것 우선:
- **무순위/잔여/임의공급** → `줍줍(자격무관)` 태그.
- 주택명·유형에서 드러나는 **소수 세대 공급** → `소수세대` (공급규모 작은 건).
- (주택형별 상세 Mdl 데이터 연동 시) 애매평형·타워형·뒷알파벳 → `빈집털이` 태그. 미연동 시 notes에 "평형별 신호는 주택형 데이터 연동 필요".
- **동시분양(같은 당첨자 발표일) 그룹**: `deadline_soon`/신규에서 발표일이 같은 단지가 2개 이상이면 묶어 `동시분양-택1` 안내(덜 선호 단지 빈집털이 힌트).

### 5. 수익 관점 (purpose에 시세차익 포함 시)
- 무순위/계약취소/임의공급 → `안전마진 기회(3~4년전 분양가)` 태그.
- 안전마진 확정 계산은 실거래가 비교가 필요 → 이 하네스 범위 밖. `apt-value`/`realprice-flow` 스킬로 후속 분석하라는 포인터만 남긴다(지식베이스 §7 원칙 요약 포함).

### 6. 우선순위 점수화
공고별 `fit_score`(0~100) 대략:
- 특공 자격 적중 +40 / 국민·민영 일반공급 경로 적합 +20 / 무순위 자격무관 +15
- 지역·면적 선호 적중 +15 / 전략 태그(줍줍·소수세대·빈집털이) +10 / 마감임박(놓치면 안 됨) +10
- 자격 불명확 −10
상위 정렬해 **"내 맞춤 TOP" 리스트**를 만든다.

{
  "profile_summary": { "household_status":"무주택세대주", "types":["신혼부부"], "est_score":42, "orientation":"민영_추첨", "purpose":"둘다", "flags":["가점_불완전"] },
  "top_matches": [
    { "name":"...", "type":"APT_무순위잔여", "route":["무순위(자격무관)"], "tags":["줍줍","마감임박 D-3"], "fit_score":75, "dday":3,
      "why":"무순위라 무주택 요건만 맞으면 지원 가능·마감임박", "confirm":"무주택 요건 공고 원문 확인" }
  ],
  "by_route": { "특별공급": [...], "일반공급": [...], "무순위_줍줍": [...] },
  "simultaneous_groups": [ { "announce_date":"2026-07-16", "notices":["A","B"], "hint":"택1 — 덜 선호 단지 빈집털이" } ],
  "notes": [ "프로필 미입력: 무주택기간·부양가족 → 가점 추정 불완전", "평형별 빈집털이 신호는 주택형 데이터 연동 필요", "최종 자격은 공고 원문 확인" ]

## 정직성
- 강의는 2024 기준. **규제(전매·실거주·투기과열지구·소득기준)는 반드시 최신 확인** 문구를 notes와 각 추천에 유지.
- 프로필이 불완전하면 무엇이 비었는지 명시하고, 추정임을 밝힌다.
- 자격을 단정하지 말고 "지원 가능 후보 + 원문 확인"으로 표현한다.
